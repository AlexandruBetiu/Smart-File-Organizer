# Project Structure

This file shows the main parts of the project in a simple way.
It helps explain where the organizer logic, terminal flow, and GUI flow are.

## Main Files
1. `app.py` starts the terminal menu
2. `gui_app.py` starts the Tkinter window
3. `organizer/organizer.py` has the main logic
4. `organizer/cli.py` has the terminal menu
5. `organizer/gui.py` has the window interface
6. `organizer/models.py` has the data models
7. `tests/test_organizer.py` has the main tests
8. `docs/` has preview images used in the README
