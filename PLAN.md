# Plan

This project is a small file organizer made with Python and OOP.
The idea is to choose a folder, pick how to classify the files, organize them, and still be able to undo the last run.

## What It Does
1. Reads files from a selected folder
2. Checks file data like extension and modified date
3. Classifies by file type, exact extension, or modified month
4. Creates the needed folders automatically
5. Moves files into the right folder
6. Saves history so the last run can be undone
7. Writes a log file for tracking

## First Steps
1. Open the project folder
2. Make sure Python is installed
3. Run the CLI or GUI version
4. Choose a folder to organize
5. Pick the classify mode
6. Start the organize process
